# SnapFire v1.2.0-rc.1

> **预发布（Release Candidate）。** v1.0.0 仍是当前 latest 稳定版；本版本用于验证 v1.2.0 系列的新菜单、长征玩法和武器系统。原 `v1.2.0` 预发布已由本版本取代。

本次更新把 **常规作战 / 长征胜利 90 周年纪念** 两级菜单、长征玩法、红军/国民党军换装，以及桌面端的 **步枪连发 / 手枪 / 换枪动画** 一起带到桌面端和手机端。

## 新增：两级作战菜单

首页最外层现在只有两个入口：

- **常规作战**
  - 单人 / 团战 / 夺旗 / 拆弹
  - 团战 → 巷战 / 野战
  - 目前只有“团战 → 巷战”接入局域网房间；其余入口保留并显示“待开发”
- **长征胜利 90 周年纪念**
  - 导读：历史背景、长征过程、历史意义、长征精神在当下的价值
  - 导读至少停留 **10 秒**，画面实时显示剩余秒数，“下一步”按时解锁
  - 常规：沿用巷战规则，阵营显示为 **红军 / 国民党军**
  - 历史场景：湘江、四渡赤水、大渡河、泸定桥等 8 场长征战役资料

## 新增：屏幕内玩家换装（长征常规）

- 战斗画面使用 **CenterNet 全帧检测**，不只检测准心目标，而是屏幕内所有可见人物
- 按人脸 / 衣着匹配到房间玩家后，按阵营在躯干位置叠加红军或国民党军军服
- 换装绘制在独立的 2D 画布上，摄像头原始帧不变；**识别与命中判定不受影响**
- 多人体检测不可用时自动退回“按人脸生成躯干框”的备用路径
- 换装目标带平滑追踪，检测间隔内不会明显跳动

## 新增：桌面端武器系统

- **步枪**：按住鼠标左键 / 空格连发，松开立即停止
- **手枪**：单击单发，射速更慢
- **换枪**：`Q` 或右下角武器按钮切换，带下沉—抬起动画；换枪期间不能开火
- 武器 HUD 显示当前武器、射击模式和“Q 换另一把”
- 连发间隔避开桌面服务端 120ms 冷却；自动射击会复用较新的识别结果以保持节奏
- 手机端同步拥有步枪连发、手枪和换枪动画

## 其他改进

- 大厅、目标提示、战斗 HUD、结算文案统一支持红军 / 国民党军
- 修复无姿态关键点时躯干裁剪的坐标混用问题，避免换装检测拿不到衣着特征
- 手机端继续由桌面大厅“手机加入”卡片提供；手机仍是纯客户端，房主必须是桌面版
- 桌面端会自动包含构建后的手机客户端（`resources/mobile-dist`）

## 已知限制

- 军服贴片目前覆盖躯干（上衣和腰带），未覆盖袖子、裤子；素材是带背景照片，近看仍有贴片感
- 只有能在房间 gallery 中匹配到身份的玩家才会换装；未建档或无法识别的路人保持原样
- CenterNet 全帧检测约每 0.7–1.6 秒一次，低端设备会增加发热和耗电
- 单人 / 夺旗 / 拆弹 / 野战 / 历史场景实际战斗仍为占位
- 阵营主题和换装是客户端显示设置，不改变房间规则；桌面和手机可以各自选择显示模式
- v1.2.0-rc.1 的新玩法尚未做真人现场验收；v1.0.0 的真人双机验收结论仍适用于基础巷战规则

## 安装

1. 下载 `SnapFire-1.2.0-rc.1-win-x64.zip` 和 `SHA256SUMS.txt`
2. 解压到任意可写目录，双击 `SnapFire.exe`
3. 创建房间后，用桌面大厅“手机加入”卡片扫码，或打开 HTTPS 客户端地址
4. 手机加入时房间地址使用 `192.168.x.x:8443`，不要使用桌面房主地址的 `:17890`

首次使用手机客户端需安装一次该房主电脑生成的 CA 证书；手机与电脑需在同一局域网。
