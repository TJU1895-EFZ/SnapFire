# SnapFire v0.1.1 测试版

SnapFire 是一个面向真实场地的**混合现实（MR）真人枪战应用**：玩家各自捧着 Windows 笔记本，把摄像头当作枪口、屏幕当作瞄准镜，在真实房间里移动、瞄准、射击。

> v0.1.1 仍是 0.x 测试版，面向小范围实测。真实双机/真人现场验收仍在进行中，不建议作为正式商业版本。

## 本次更新

- **场地测试日志**：设置中可启用逐枪 JSONL 日志，记录识别分数、识别来源、耗时和服务端结果；默认关闭，只写本机，不记录图像。
- **FIELD TEST 面板**：战斗中可标注距离、朝向、光照和意图目标，用数字键 `1`~`6` 选择目标、`0` 清除；每枪显示结果。
- **实地测试工作流**：新增 `field-tests/_templates/`、现场记录表和数据复核规范，便于把 JSONL 整理成 `shots.csv`。
- **冒烟覆盖**：自动化冒烟新增对 `session`、`shot`、`match-end` 三类日志的校验。
- **文档**：同步更新测试报告、发布检查清单和 README 的版本信息。

## 下载

- `SnapFire-0.1.1-win-x64.zip` — 便携版
- `SHA256SUMS.txt` — SHA256 校验值

## 运行

1. 下载 zip，解压到任意可写目录（例如 `D:\Games\SnapFire`）。
2. 双击 `SnapFire.exe`。
3. 首次启动会停留约 10 秒加载/预热本地识别模型。

- 无需 Node.js，无需安装，不创建桌面/开始菜单快捷方式。
- Windows 10/11 x64；需要摄像头。
- 数据保存在 `%APPDATA%\SnapFire\data`；删除解压目录不会删除战绩。
- 未签名版本可能触发 Windows SmartScreen：点“更多信息 → 仍要运行”（仅在你信任来源时）。

## 快速开始

1. 首页 → 团战 → 巷战（室内）。
2. 房主点「创建房间」，记下 `IP:端口` 和 4 位房间号。
3. 其他玩家在同一局域网加入，输入地址和房间号。
4. 每人完成正面 + 背面建档；选择红队/蓝队。
5. 非房主点「准备」；房主确认开局检查后点「开始比赛」。
6. 空格 / 鼠标左键开火，Esc 离开本局。

## 场地测试日志

设置 → 场地测试日志 → 启用逐枪日志。日志写入：

```text
%APPDATA%\SnapFire\field-logs\field-YYYYMMDD.jsonl
```

只保存在本机，不随备份导出，也不会上传。详细字段和整理流程见仓库 `field-tests/README.md`。

## 已知限制

- 真实双机/真人现场验收尚未完成；10 米识别、逆光、相似服装仍需现场校准。
- 10 米处人脸通常不可用，主要靠衣着；识别不确定时按未命中处理。
- 当前为风格化占位 3D 美术，不是最终模型。
- 不做身体部位差异伤害、换弹/多武器、野战、登录/云/手机端。
- 无断线重连、正式安装包、自动更新、代码签名。
- 本地 JSON 未加密，请勿在公用电脑保存敏感照片。
