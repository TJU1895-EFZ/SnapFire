# SnapFire v1.1.0-rc.1

> **预发布（Release Candidate）。** v1.0.0 仍是最新稳定版；本版本用于验证可选的手机客户端。

## 新增：手机浏览器客户端（可选）

- 桌面端创建房间时，主进程自动启动 **HTTPS + WSS** 手机服务，桌面联机协议不变。
- 大厅“手机加入”卡片显示：
  - 手机客户端地址（`https://电脑IP:8443`）
  - 安装页地址（`http://电脑IP:8444`）
  - **二维码**：手机扫码打开安装页
  - 本地 CA 证书路径和“打开证书目录”
- 安装页提供：
  - CA 证书下载（`snapfire-ca.crt`）
  - Android / iOS 安装步骤
  - “打开手机客户端”按钮和当前房间号
- 首次使用只需在每台手机上安装一次 CA；之后直接打开客户端地址输入房间号。
- 手机端支持：本地建档、触屏扳机 + 滑动选目标、摄像头 AR、准心识别、开火扣血、阵亡复活、结算、PWA。
- 手机端不传视频/照片，只同步识别特征。

## 桌面端变化

- 自动生成本地 CA 和短期服务器证书（`%APPDATA%\SnapFire\mobile-certs`）。
- 大厅新增手机加入卡片和二维码，不影响原有桌面加入/开始比赛流程。
- 打包自动包含手机端 `resources/mobile-dist`；`npm run prepare:mobile` 可手动准备。
- 手机端资源缺失时，桌面房间仍可正常使用，大厅会提示手机服务未启动。

## 安装与加入

1. 下载并解压 `SnapFire-1.1.0-win-x64.zip`；
2. 运行 `SnapFire.exe`，创建房间；
3. 手机与电脑连接同一 Wi-Fi；
4. 手机扫码打开安装页 → 下载并安装 CA 证书 → 打开手机客户端；
5. 输入大厅显示的房间号 → 选队 → 准备 → 建档；
6. 房主在桌面端开始比赛。

首次运行会提示 Windows 防火墙放行 8443（客户端）和 8444（安装页），请允许“专用网络”。

## 验证

- 桌面：`typecheck`、35 个单元测试、`build`、完整双机 `test:smoke`、`smoke:mobile`（源码 + 打包 exe）、`dist:win`。
- 手机：`typecheck`、21 个单元测试、`build`、`smoke:lan`、`smoke:app` 全流程。
- 打包版 `smoke:mobile` 确认：HTTPS 页面 200、模型 200、安装页 200、CA 下载 200、二维码存在、WSS 加入房间成功。

## 已知限制（预发布）

- 手机首次使用需安装一次 CA 证书；这是浏览器 HTTPS 安全要求的限制。
- M8（真机 AI 性能实测）和 M9（真实桌面 + 手机完整对局）尚未执行，本版本为候选版，暂不建议替代 v1.0.0 作为稳定版。
- 不同房主电脑会生成各自的 CA；换房主电脑需要重新安装该电脑的 CA。

## 校验

下载 `SHA256SUMS.txt` 并核对 zip：

```powershell
Get-FileHash .\SnapFire-1.1.0-win-x64.zip -Algorithm SHA256
```
