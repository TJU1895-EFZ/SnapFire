# SnapFire v1.0.0

SnapFire（SnapFire MR 实景枪战）是一款面向真实场地的**混合现实（MR）真人枪战应用**：玩家各自捧着 Windows 笔记本，把摄像头当作枪口、屏幕当作瞄准镜，在真实房间里移动、瞄准、射击。

## 本次发布

v1.0.0 是 SnapFire 的第一个正式版本。核心功能已完整实现并通过真人实战验收：

- **真人实战验收通过**：2026-10-24 LAN 房间 2 场实战（4v4 + 5v4，共 696 枪），红线指标（错误归属 = 0）通过。
- **局域网联机**：房主创建房间，其他玩家通过 IP:端口 + 4 位房间号加入；最多 6 人（红蓝各 3 人）。
- **真人识别**：离线人脸 + 衣着特征识别；准心锁定目标，识别不确定时按未命中处理。
- **完整战斗闭环**：建档 → 选队 → 准备 → 开战 → 扣血/复活/计时 → 结算 → 历史战绩。
- **数据持久化**：本地 JSON 存储，自动/手动备份、导出/导入。
- **场地测试支持**：逐枪 JSONL 日志、FIELD TEST 面板，便于采集识别数据。

## 下载

- `SnapFire-0.1.1-win-x64.zip` — 便携版（约 158MB）
- `SHA256SUMS.txt` — SHA256 校验值

## 运行

1. 下载 zip，解压到任意可写目录。
2. 双击 `SnapFire.exe`。
3. 首次启动会停留约 10 秒加载/预热本地识别模型。

- 无需 Node.js，无需安装，不创建桌面/开始菜单快捷方式。
- Windows 10/11 x64；需要摄像头。
- 数据保存在 `%APPDATA%\SnapFire\data`；删除解压目录不会删除战绩。
- 未签名版本可能触发 Windows SmartScreen：点"更多信息 → 仍要运行"（仅在你信任来源时）。

## 快速开始

1. 首页 → 团战 → 巷战（室内）。
2. 房主点「创建房间」，记下 `IP:端口` 和 4 位房间号。
3. 其他玩家在同一局域网加入，输入地址和房间号。
4. 每人完成正面 + 背面建档；选择红队/蓝队。
5. 非房主点「准备」；房主确认开局检查后点「开始比赛」。
6. 空格 / 鼠标左键开火，Esc 离开本局。

## 已知限制

- 识别正确率：实战场景下综合正确率约 17.8%（非受控测量场）；Jason 最佳数据 49.3%（3 米正面）。漏识别率 78.7% 是主要体验瓶颈。
- 10 米处人脸通常不可用，主要靠衣着；逆光、暗光、相似服装会降低成功率。
- 当前为风格化占位 3D 美术，不是最终模型。
- 不做身体部位差异伤害、换弹/多武器、野战、登录/云/手机端。
- 无断线重连、正式安装包、自动更新、代码签名。
- 本地 JSON 未加密，请勿在公用电脑保存敏感照片。
- 未进行 6 米/10 米测量场测试、6 人房间测试、连续 3 局稳定性测试。
